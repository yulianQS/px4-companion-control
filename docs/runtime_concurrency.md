# 并发与性能记录

## 执行分工

| 工作 | 执行位置 | 调度与数据约束 |
| --- | --- | --- |
| MAVLink 接收 | C++ `mavlink-rx` | 独立读取 UART，不等待网页和图像 |
| 设定值输出 | C++ `fc-tick-20Hz` | 单一 20 Hz 输出源，不让多个任务并行争抢飞控 |
| 比赛编排 | C++ `mission-run` | 独立调度线程，积木按连接顺序执行；与采集、识别、日志并行 |
| 视觉反馈缓存 | C++ `vision-cache` | 20 Hz 读取本地快照；图像处理不进入输出线程 |
| 飞行记录 | C++ `flight-csv` | 独立有界队列写盘，不在控制循环同步写 CSV |
| 指令与客户端 | C++ `tcp-command` / `tcp-client` | 客户端收发与命令执行分开，20 Hz 输出不等待 ACK |
| 相机 | ROS2 `camera-capture` | 连续采集，软件发布目标 30 fps，保留现有曝光与标定 |
| AprilTag | ROS2 `tag-detect` | OpenCV 4 线程，订阅只留最新一帧，避免处理陈旧积压 |
| 视频预览 | ROS2 `preview-jpeg` | 目标 10 fps，单张最新图像；复制、画框与 JPEG 不按每次检测重复执行 |
| 本地状态与网页 | ROS2 / Python API | 状态快照与视频独立；无线断连不参与本地飞行闭环 |

当前实测 CPU 为 6 个 Cortex-A55 和 2 个 Cortex-A76。保留 Linux 调度，不固定核心、不启用实时 FIFO、不关闭系统温控。任务可并行计算，但飞行设定值必须保持一个输出源。

## 采样和 htop

在开发板工程目录执行：

```bash
/home/pi/venv/bin/python -B scripts/profile_runtime.py --seconds 60 --label flight-check --htop
```

该命令只读采样，不启动飞行、不修改 PID 或调度策略。输出到 `logs/performance/<板上UTC时间>-<标签>/`：

- `htop.typescript`：htop 终端录屏，包含刷新时的转义序列；用终端 `cat` 查看，不能当 CSV 解析。
- `threads.csv`：逐线程 CPU、运行核心、CPU 亲和范围、每个采样区间的调度等待毫秒数。
- `system.csv`：温度、频率、温控状态、CPU 累计计数、内存和系统支持时的 PSI。
- `summary.json`：观察结果与 JPEG 更新率、接收后时间、包含图像处理的测量年龄。
- `metadata.json`：本次配置、CPU 信息、启动标识；板上时钟可能与电脑不同，跨记录对照要核对 boot ID。

实时交互查看可运行 `htop -t`，在设置中显示用户线程和线程名称。录屏使用本次输出目录中的独立 htop 配置，不覆盖用户设置。

更新率由共享内存中的新时间戳统计；不是相机传感器帧率，也不代表目标始终有效。`scheduler_wait_ms` 是采样区间累计排队时间，不是最大单次控制延迟。当前板上内核未提供 `/proc/*/schedstat`，该列留空，metadata 标记不支持；不以 0 冒充无等待。空闲采样不能代替飞行负载验证。

## 本次对照原则

先记录现有配置，再分别比较限制核心范围、OpenCV 2 线程和原 4 线程；不在编译期间统计运行帧率。温度约 90°C 且存在 `idle_inject` 降温线程时，增加线程可能被温控抵消。优先比较持续更新率和测量年龄，不能只看 CPU 占用率高低。

若温度持续约 90°C，应改善散热和通风后再对比线程数；保留温控，避免用超频或关闭温控掩盖瓶颈。当前测试保留 4 个 OpenCV 线程，其他硬件继续实测，不套用固定核心布局。

本次约 20 秒一组的顺序采样：

| 设置 | 观测更新 / s | JPEG 更新 / s |
| --- | ---: | ---: |
| 原版，4 线程 | 13.65 | 9.87 |
| 限制核心分工，4 线程 | 12.80 | 9.91 |
| 原版，2 线程 | 12.42 | 9.23 |
| 预览按需生成，4 线程 | 12.76 | 9.72 |
| 预览按需生成，6 线程 | 12.46 | 9.62 |
| 预览按需生成，8 线程 | 11.75 | 9.11 |

4 线程恢复后另用 ROS 小消息订阅计数，10 秒样本测得：相机发布 29.07 fps、检测输出 13.59 fps、JPEG 9.89 fps；检测年龄平均 94.09 ms、最大 152.55 ms。该计数不读取大图像，也不发送飞控指令。

这些是热机、固定场景的短时间顺序测试，并非同温度下严格 A/B，也不能证明所有场景的全局最优。当前没有证据表明代码改动显著提高了帧率；保留按预览频率生成画面的改动是为减少无用复制/画框，不改变逐帧检测。6/8 线程和固定核心均未保留。实际带目标、无线视频负载及飞行震动仍需单独记录验证。
