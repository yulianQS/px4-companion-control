## 实际接口和操作顺序

1. 观察真实遥测，启用实机控制。
2. 未解锁时选择OFFBOARD并切换：开发板先发送至少1.5秒零速度，再等待COMMAND_ACK与新心跳确认。
3. 点击“解锁”：普通MAV_CMD_COMPONENT_ARM_DISARM参数[1,0,0,0,0,0,0]；不使用强制值，不修改PX4检查。需在地面、新鲜速度估计、双向链路、当前4S电池电压至少14.4V。
4. 可在地面直接启用摇杆，不要求先起飞；未解锁时只用于设定值调试。实际动作需手动解锁，解锁会先清除地面调试杆量，之后重新启用摇杆。也可以单独点击“起飞”，按输入相对高度与速度开始闭环任务，不自动解锁。网页不再附加10秒自动上锁计时；PX4自身自动上锁配置保持原状。
5. 飞控确认在空中后，可以执行平移、转向或升降。每次只执行一项任务，参数均由后端检查。
6. 点击“降落”：请求PX4 LAND模式；模式接受仅表示进入降落，不等于已落地。新鲜落地状态持续1秒后，必要时请求普通地面上锁；落地且上锁才标记完成。

这是一套真实控制接口；本轮软件接入不等于装桨飞行验证通过。

## 运动坐标、范围和完成条件

- 平移：方向以任务开始时机头为准，转换成固定局部NED目标，途中转动机头不会改变既定方向。距离0.1～5m，速度0.05～0.5m/s，误差0.01～0.5m。
- 升降/起飞：局部z向下为正，上升目标z减小。高度变化0.1～2m，速度0.05～0.3m/s，误差0.01～0.5m；默认起飞0.5m、0.2m/s。局部高度不是离地高度。
- 转向：俯视顺时针为正；累计实际偏航变化，支持跨±180度与完整360度。转角1～360度，角速度5～60度/s，误差1～15度。使用相对航向，不因此获得绝对北向或长期无漂移航向。
- 运动超时2～120秒；允许误差必须小于目标距离/转角。水平及垂直加速度限制0.3m/s²，偏航角加速度限制60度/s²。
- 开发板20Hz任务线程计算局部NED速度与偏航角速度，MAVLink frame=1、type_mask=1479；PX4负责内部姿态/速度控制。网页只提交任务并显示反馈。
- 完成需目标误差达标、低速度、横向/高度保持条件满足，并连续稳定至少0.5秒和至少3个不同位置样本；到达后继续保持目标。起飞还需飞控确认在空中。
- 取消或超时：停止原目标，反馈有效时保持当时局部位置；不等于电机停转。正在执行PX4 LAND时不提供取消后自动悬停。
- 位置/姿态陈旧、ODOMETRY重置计数缺失或改变、飞控时间回退、偏航不连续跳变、模式退出、上锁、会话过期均会锁止原运动任务，不自动重放。发送线程停更超过0.3秒会停止原任务。

任务反馈要求新鲜位置<1秒、姿态<0.5秒、ODOMETRY<1秒、估计器<6秒（当前状态消息约5秒一次）；ESTIMATOR_STATUS需水平/垂直速度与相对水平/垂直位置有效，掩码46，且无CONST_POS_MODE。旧速度有效判断误用了12，本版按协议修正为6。收到数值不等于有效估计。

## 关闭和状态含义

地面“普通上锁 / 停转”只发送普通上锁，不提供空中停机。关闭实机控制时，地面先上锁并退出Offboard；空中或未确认落地时请求LAND，确认落地上锁后才关闭控制。LAND拒绝/未知时不伪装关闭成功。结束进程时若有空中飞行任务，会尝试请求LAND；退出程序不代表飞控已落地。

COMMAND_ACK与新心跳分别显示。ACK接受不等于模式/解锁状态改变；任务accepted只表示提交成功。遥测缺失、NaN、陈旧显示“—”；离线不回退模拟数据。页面进度、误差和轨迹来自真实任务反馈；降落没有虚构距离百分比。

## 结构与接口

- web_control.py：标准库HTTP、静态资源、同源检查、JSON接口与局域网网址打印。
- web_flight.py：扩展PX4Link遥测，唯一串口持有者、控制租期、请求去重、普通命令、20Hz发送与收尾线程。
- motion_tasks.py：纯任务计算模块，无串口访问；参数、相对目标、速度闭环、真实完成判据、取消/超时/降落监测。
- web/index.html、style.css、app.js：界面、单控制开关、任务提交和真实反馈呈现。
- scripts/verify_web_control.py、verify_motion_tasks.py：离线FakeLink与pymavlink编码验证，不访问UART或驱动电机。

GET /api/status只读。POST /api/control/claim、renew、action自动携带X-Control-Request: 1、X-Client-ID，JSON最多4096字节；拒绝跨站Origin。控制租期20秒、网页每5秒续期；操作串行，最近128个request_id去重。action支持mode、arm、disarm、disable、release、task_start、task_cancel、takeoff、land；task含kind、direction、distance、speed、tolerance、timeout。没有任意MAVLink命令或参数写入接口。重启后清除内存任务、缓存与控制权，不自动恢复动作。
