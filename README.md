# 无人机控制工程

本地工程：`F:/rmfly/drone_project`。开发板：`pi@192.168.137.3:/home/pi/drone_project`。

## 控制链路

浏览器 → Python HTTP/API（8081）→ TCP JSON（8090）→ C++ 比赛调度 / 视觉闭环 / 运动控制 → MAVLink UART → PX4。

ROS2 C++ 相机、AprilTag 与跟随节点发布 `/dev/shm/drone_vision/status.json`，C++ 控制进程直接读取视觉反馈。比赛调度由 C++ 独立执行，Python 与网页退出不会停止任务；控制进程退出则不能继续执行。

网页断线不取消已受理的自动起飞、轨迹、定时速度或视觉任务，也不停止机载设定值发送。
20 秒网页控制租期只约束新命令，过期后需重新取得控制权；手动摇杆仍在 0.5 秒无输入时回中保持。
比赛由 C++ 本地调度并续租。视频连接只读取最新 JPEG，慢连接丢帧或断开，不参与视觉反馈和飞行闭环。
任务自身超时、PX4/本地视觉故障及显式停止仍按原逻辑处理；尚未被后端受理的命令不保证在断线后执行。

比赛运行区的“一键停转电机”单击请求 PX4 强制上锁（MAVLink 400，参数 0/21196），同时终止比赛和机载控制输出，不执行降落。空中点击会失去动力；页面仅在飞控新心跳确认上锁后报告成功。再次使用 Offboard 控制需手动重新设置模式及解锁。

视觉对准后接距离保持/视觉跟随时，使用有效标定测距和粗水平对准条件交接，不等待垂直居中；保持同一 C++ 视觉会话，进入距离阶段后同步执行偏航、升降和距离控制。距离阶段仍按距离容差、已启用轴的居中条件及达标时长判断完成。

“距离保持”积木的“恒定前后速度”大于 0 时，距离过远下发正向设定速度、过近下发反向设定速度，进入本积木原有距离容差时下发零速度并保持位置。例如填写 4，发送给 PX4 的机体前后速度目标就是 ±4 m/s，不再由距离 P/I/D 缩小，也不套用搜索阶段的加速度斜坡；偏航、升降、横移和目标丢失处理保留原逻辑。填写 0 时沿用原距离 PID，其他视觉任务仍使用原 PID 幅值语义。实际速度、加速和制动由 PX4 跟踪，设定值不代表飞机能瞬间达到该速度；比赛监控分别显示实测速度和前后速度目标。

## 配置

- `config/runtime.json`：串口、网络端口、Python 环境、视觉快照目录及目标连续性参数。
- `config/mission_blocks.json`：17 个基础飞行、视觉积木的统一定义；Python 与 C++ 共用。
- `config/vision_control.json`：视觉 PID、幅值、标记尺寸及目标距离的持久化默认值。网页和比赛共用，部署时保留板上文件。
- `config/vision.yaml`：ROS2 相机和识别节点配置。

比赛积木的速度与角速度不设工程层上限，也不再由 C++ 隐式截到 0.2 m/s 或 30°/s。
运动速度仍需为有限正数，视觉输出幅值 `0` 表示不截断 PID 输出；PX4 自身控制参数保持原值。
平移、升降、坐标、悬停和航点任务可设置 `acceleration`，旋转可设置 `angular_acceleration`；
默认沿用原参考加速度，设 `0` 关闭参考速度斜坡。搜索接近的加速度同样支持 `0`。
速度高但距离短时，有加速度斜坡的参考轨迹未必能达到设定速度。

视觉外环的偏航、升降、俯仰/前后距离、横滚/横移分别保留自己的 P/I/D，所有视觉任务读取同一份
`config/vision_control.json`。任一页面保存后，C++ 本地读取线程在约 0.25 秒内更新运行中的视觉参数，
下一个任务继续使用这些默认值；旧三轴文件自动兼容。横移默认关闭，启用后按归一化水平像素误差生成机体右向速度，
与前向速度共同转换到 NED；姿态与电机控制继续使用 PX4 原控制器。基础飞行任务仍走 PX4 位置控制。

采集、视觉检测、JPEG 预览编码、比赛调度与 20 Hz 飞控输出分别运行；只由控制线程合成飞控输出。
`tag_detector_node.opencv_threads` 配置检测内部并行线程数，板上对比后默认 4；
`preview_fps` 默认 10，只限制独立 JPEG 工作线程，不限制检测。预览仅保留最新待编码图像，不积压帧。
历史实时采样：改动前识别约 8.6 FPS；新链路 2 线程约 13.5 FPS、4 线程约 19.9 FPS，
4 线程时相机发布约 28 FPS、JPEG 约 9.2 FPS、检测消息平均年龄约 64 ms。保留 4 线程；这些为当前场景采样，不保证所有场景同速。

### 相机曝光

`config/vision.yaml` 的 `camera_node.ros__parameters.exposure_time_us` 控制实际快门时间：
默认 `2000` 为 2 ms（1/500 秒），光照足够时可试 `1000`；`0` 恢复自动曝光。
固定快门使用 ISP 的快门优先模式，增益由 ISP 自动调节。短曝光会降低进光量。
`publish_fps: 30.0` 只控制软件发布频率，不控制曝光时间。

此接口针对本板 Allwinner ISP，`isp_device` 默认 `/dev/v4l-subdev12`（`sunxi_isp.0`）。
该 ISP 的曝光控制值单位是微秒，不能套用标准 V4L2 的 100 微秒单位。
C++ 相机节点收到首帧后设置一次并检查控制读回，重连时重新应用；设置失败会报告 `camera_error`。
曝光生效存在 ISP/传感器帧延迟，首帧不作为已生效的证明。采集、曝光设置和 AprilTag 识别均由 C++ 执行，
不会每帧启动外部命令或经过 Python 处理图像。修改配置后需重启视觉节点；启动日志显示所请求的曝光值。

## 起飞高度

“自动起飞”的高度是相对本次起飞地面的上升量。C++ 在请求时记录地面局部 Z，目标为 `地面 Z − 高度`，复用现有轨迹参考及 PX4 Offboard 位置控制，不再向 Navigator 发送原生起飞命令，也不写入 `MIS_TAKEOFF_ALT`。未填写起飞速度时读取 `MPC_TKO_SPEED`，填写时使用填写值；到高和速度稳定后保持位置。比赛监控显示“相对起飞点高度”，原始局部坐标仍保留。

光流、ToF 和气压高度继续由 PX4 EKF 融合，不新增第二套测距 PID。局部估计精度仍取决于实际传感器和融合状态。

## 验证

日志目录、时间戳命名、任务与 CSV 对齐、中断恢复及落盘规则见 [板端工程日志与保留规则](docs/log_storage.md)。

“相对位移”积木先制动回正，再执行前后左右或升降位移。回正阶段发送零水平速度，保持进入时的高度和航向，由 PX4 原控制器执行；默认要求横滚、俯仰都在 ±5° 内，三轴合速度不超过 0.2 m/s，并在新鲜反馈下连续稳定 0.5 秒。积木参数可调整角度、速度、稳定时间和回正最长等待时间（默认 10 秒）；回正超时会失败并保持位置，不执行位移。距离从回正后的位置计算，方向仍按进入积木时的机头方向；回正等待计入整个积木超时。运行状态和任务日志区分 `leveling` 与 `moving` 阶段。直接调用原有 `MOVE` 接口不改变默认行为。

比赛编排的运行监控区显示前置实时视觉画面，与运动页面共用同一条视频流；画面旁保留原“一键停转电机”按钮。图像超过两秒未更新时隐藏旧画面并提示重连，视频中断不影响停转按钮发出请求。

视觉链共用 C++ 目标状态和一个持续运行的视觉控制会话。搜索时目标闪现即取消原广域扫描并开始缓慢接近，不等识别确认才移动。按当前航向和现有前视相机有效目标位姿记住目标方位，没有位姿时沿发现时机头方向。默认接近速度 0.1 m/s、加速度 0.2 m/s²，均可在搜索参数中保存；转向按扫描角速度平滑调整，搜索阶段保持高度。短暂漏检默认继续沿最后目标方位前进 2 秒；超出该时间平滑减速并在方位附近扫描（默认 ±10°），保持同一积木、同一会话，不重新执行广域搜索。

“搜索并确认目标”将扫描、接近和识别确认放在同一积木内，达到有效确认时间（默认 0.5 秒）后直接进入对准。目标几何默认保留 0.5 秒，短暂漏检和单帧跳变暂停累计；超过保留时间后清空证据，不跨跟踪周期累计。搜索与识别共用跟踪器证据，旧任务紧接的识别积木复用搜索确认结果，不重复等待。网页加载旧草稿或任务时合并直接相连、没有其他入口的搜索和识别，保留原识别时长与后续连接；单独使用的识别、锁定和 AprilTag 积木继续兼容。识别和粗对准丢失目标时按原有丢失参数恢复，不再因搜索接近会话而跳过恢复。搜索每两秒记录阶段、跟踪周期和确认进度。距离保持采用恒速；速度为 0 时使用原距离 PID，跟随逻辑不变。大于归一化距离 0.25 的中心跳变仍需两帧一致检测；旧框和重复快照不能虚增识别或对准进度。任务原超时、用户停止和显式降落仍生效。

视觉对准后直接接距离保持/跟随时，默认采用水平 80 px、垂直 60 px、有效 0.1 秒的粗对准交接；靠近时继续转向和垂直控制。单独对准仍使用原精度参数。各阶段用 `VISION_UPDATE` 复用控制会话，仅重置发生参数变化的 PID 通道。距离保持的目标丢失仍从真实检测中断开始计时，按原 NED 前进向量续行配置时间（默认 3 秒）后恢复搜索；识别和对准阶段不沿旧方向前进。视觉 PID、速度幅值和持久化默认值不变。
